Refactor halaman /kids-private agar mengikuti seluruh sistem website yang sudah ada.

Requirements:

1. Dark Mode Support

* Gunakan theme provider yang sudah digunakan oleh halaman lain.
* Jangan membuat implementasi dark mode baru.
* Gunakan design token yang sudah ada.

Pastikan:

* Background berubah sesuai theme.
* Card tetap memiliki kontras yang baik.
* CTA tetap menonjol.
* Ilustrasi tetap terlihat baik di dark mode.

2. Multi Language Support

* Gunakan sistem locale/i18n yang sudah dipakai website.
* Jangan hardcode text.

Semua text harus menggunakan translation key.

Contoh:

t("kids.hero.title")
t("kids.hero.subtitle")
t("kids.programs.title")

Buat translation file untuk:

* English
* Indonesian

3. Reusable Components
   Pisahkan section menjadi component:

components/kids/
├── HeroSection
├── ProgramSection
├── WhyChooseUsSection
├── LearningJourneySection
├── TestimonialSection
├── FAQSection
└── CTASection

4. Theme Tokens
   Gunakan token global website:

--primary
--accent
--background
--foreground
--card
--border

Jangan menggunakan warna hardcoded.

5. Accessibility

* Dark mode harus tetap readable.
* Semua icon dan illustration harus memiliki kontras yang cukup.
* Support keyboard navigation.

6. Branding
   Gunakan logo dari /public/logo.

7. Future Scalability
   Pastikan section baru dapat ditambahkan tanpa mengubah struktur halaman utama.

8. Premium UI

* Glassmorphism ringan
* Soft shadows
* Smooth transitions
* Hover animations
* Responsive design

Tujuan:
Halaman /kids-private harus terlihat sebagai bagian dari website utama, bukan halaman yang dibuat terpisah.
